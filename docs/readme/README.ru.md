# Mibo

**ИИ-компаньон, который живёт на рабочем столе: составляет компанию и выполняет дела.**

Персонаж со своим обликом и характером общается с вами, помнит вас и приносит по одной вещи, достойной вашего времени. Он не только беседует: просматривает веб-страницы, управляет программами на компьютере, работает с файлами и командами, использует навыки и MCP-коннекторы и выполняет задачи по расписанию. Он работает на вашем компьютере с выбранным вами сервисом моделей. Действия проверяются автоматически, а персонаж спрашивает в чате, только когда нужно ваше решение: после вашего согласия задача выполняется до конца; об оплате, удалении и изменениях учётной записи спрашивается отдельно.

## Возможности

| Область | |
|---|---|
| **Общение** | Один персонаж — в окне, а в Windows ещё и в виде фигурки на рабочем столе. Встроенные персонажи или собственные. Любой OpenAI-совместимый сервис либо Ollama и LM Studio на вашем компьютере. Меню модели показывает заполненность контекста и предлагает «Сжать сейчас» и «Очистить контекст». |
| **Память** | Факты и планы о вас с датами, доступные для просмотра и правки в разделе «Настройки › Память». Номера документов и карт, пароли и коды никогда не сохраняются. Временные чаты не оставляют записей. |
| **Рекомендации** | По одной находке за раз из открытых источников, с ранжированием по времени, которое вы им уделяете, а не по кликам. Каждая карточка указывает причину и принимает отзыв с возможностью отмены. |
| **Прогулки** | Обходит открытые страницы как посетитель, без входа в аккаунты и с соблюдением robots.txt. Страница читается целиком сразу, с заголовками и таблицами. Для веб-поиска ключ не нужен. |
| **Встроенный браузер** (Windows) | Ссылки открываются рядом с диалогом: вкладки, приватные вкладки, загрузки. Персонаж просматривает страницу и нажимает, вводит текст, выбирает, перетаскивает и загружает файлы. |
| **Другие программы** (Windows) | Читает окна других программ и управляет ими через UI Automation, включая приложения на Electron, и только пока вы не пользуетесь клавиатурой и мышью. |
| **Файлы и команды** | Только в ваших папках «Рабочий стол», «Документы», «Загрузки», «Изображения», «Музыка» и «Видео» и в папках, которые вы разрешили. Команды разбираются до запуска; изменения файлов за каждый ход можно отменить; в Windows удалённое попадает в корзину. |
| **Навыки и коннекторы** | Навыки (папки с `SKILL.md`) и MCP-серверы, у каждого — отобранный каталог. Сообщение, начинающееся с `/name` (имени навыка), запускает этот навык. |
| **Задачи по расписанию** | Напоминания, задачи и периодические проверки условий. При запуске они только читают, а также выполняют то, что вы разрешили при создании. |
| **Языки** | Десять языков интерфейса. |

## Установка

Скачайте [последний выпуск](https://github.com/wangkant/mibo/releases/latest). Установщики не подписаны, поэтому перед первым запуском система показывает предупреждение.

| Система | Файл | Первый запуск |
|---|---|---|
| Windows 10 или 11 (x64) | `mibo-0.1.0-setup.exe` | Если браузер предупреждает о файле, выберите **Сохранить**. Когда SmartScreen покажет «Система Windows защитила ваш компьютер», выберите **Подробнее**, затем **Выполнить в любом случае**. Установка выполняется только для вашей учётной записи и не требует прав администратора. |
| macOS (Apple silicon) | `mibo-0.1.0-macos-arm64.dmg` | Откройте образ диска и перетащите `mibo.app` в папку «Программы». Первое открытие блокируется, так как приложение не нотаризовано: закройте сообщение, затем в разделе «Системные настройки › Конфиденциальность и безопасность» выберите **Все равно открыть** и подтвердите. |

Новые выпуски устанавливаются так же, поверх старых. При удалении папка с данными сохраняется.

### Без установщика

| | |
|---|---|
| **Windows, портативная версия** | Скачайте `mibo-0.1.0-windows-x64.zip`, распакуйте в любую папку и запустите `mibo.exe`. Файл также не подписан. |
| **Scoop** (Windows) | Выполните `scoop bucket add mibo https://github.com/wangkant/scoop-mibo`, затем `scoop install mibo`. |
| **Homebrew** (macOS, Apple silicon) | Выполните `brew install --cask wangkant/mibo/mibo`. |
| **Через Python** (3.10–3.14, любая система) | Выполните `pipx install "mibo[app,web]"` или `uv tool install "mibo[app,web]"`, затем запустите `mibo`. |

### Из исходного кода (Linux и разработка)

Требуется Python 3.10–3.14.

```bash
git clone https://github.com/wangkant/mibo
cd mibo
python -m pip install -e ".[app,web]"
mibo
```

`app` добавляет оконную библиотеку в macOS и Linux, `web` — Playwright для прогулок. Для разработки установите `".[dev]"` и запустите `python -m pytest -q`; подробнее — в [CONTRIBUTING](../../.github/CONTRIBUTING.md) (на английском).

## Первый запуск

1. Выберите язык, персонажа и модель, затем интересующие вас темы и пару слов о себе.
2. Для модели выберите сервис и вставьте его ключ, войдите через OpenRouter, чтобы пользоваться его бесплатными моделями, или выберите запущенные Ollama или LM Studio.
3. Ключ хранится в системном хранилище учётных данных (диспетчер учётных данных Windows, связка ключей macOS, Secret Service в Linux) и никогда не записывается в файл. В системе без такого хранилища он хранится в `credentials.json`, доступном для чтения только вашей учётной записи, о чём сообщает раздел «Настройки › Этот компьютер».

Данные хранятся в одной папке: `~/mibo` для установленной копии, сам клон при запуске из исходного кода или папка, указанная через `mibo --home DIR`. Настройки хранятся там же, в `settings.json`. По умолчанию Mibo запускается при входе в систему; отключить это можно в разделе «Настройки › Этот компьютер».

## Конфиденциальность и безопасность

| | |
|---|---|
| **Ваш сервис моделей** | Получает ваши сообщения, относящиеся к делу воспоминания, страницы и файлы, использованные для ответа, и шаги, которые оценивает проверка. Ваш ключ отправляется только ему. |
| **Сайты** | Прогулки читают открытые страницы без входа в аккаунты, по умолчанию три раза в день («Настройки › Прогулки»); ответ читает нужные ему страницы. Ваши входы в аккаунты остаются во встроенном браузере и используются только там. |
| **Другие сервисы** | Поисковый запрос, когда ответу нужен поиск; номер версии для GitHub не чаще раза в день; запросы к каталогу при открытии магазина; то, что персонаж передаёт инструментам MCP-сервера. |
| **Всегда спрашивает** | Оплата и покупки, удаление, изменение безопасности или доступа учётной записи — в любом режиме; согласие на шаг другого рода на них не распространяется. Любое действие на сайтах банков, платёжных и медицинских сервисов и почты. Согласием считается только ваше собственное сообщение, набранное в чате. |
| **Никогда** | Чтение и ввод паролей, платёжных данных и кодов подтверждения; запуск чего-либо от имени администратора; изменение настроек безопасности. |
| **Без присмотра** | Только прогулки и созданные вами задачи по расписанию. |

В [SECURITY](../../.github/SECURITY.md) (на английском) перечислены все адресаты и места хранения каждого вида данных.
