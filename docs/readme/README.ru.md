# Mibo

Компаньон для рабочего стола. Один персонаж общается с вами, помнит вас, рекомендует по одной вещи за раз и действует за вас в интернете, в других программах и в ваших файлах. Любое действие с последствиями ждёт вашего подтверждения.

Mibo работает локально с выбранной вами моделью и хранит данные в одной папке на вашем компьютере. Целевые системы — Windows 10 и 11.

> **Статус:** предварительная версия. Установщик пока не опубликован; запускайте из исходного кода.

## Возможности

| | |
|---|---|
| **Общение** | Один персонаж — в окне и в виде фигурки на рабочем столе. Встроенные персонажи или собственные. Любой OpenAI-совместимый сервис моделей с вашим ключом. |
| **Память** | Факты и планы о вас с датами, доступные для просмотра и правки в настройках. Чувствительные данные (номера документов и карт, пароли, коды) никогда не сохраняются. |
| **Рекомендации** | По одному материалу за раз из открытых источников, с ранжированием по времени, которое вы им уделяете, а не по кликам. Каждая карточка указывает причину и принимает отзыв с возможностью отмены. |
| **Веб** | Читает открытые страницы как посетитель и соблюдает robots.txt. Встроенный браузер показывает диалог рядом со страницей и управляет страницей по запросу. |
| **Программы** (Windows) | Находит другие программы и управляет ими через UI Automation, с согласием для каждой программы и никогда во время вашего ввода. |
| **Файлы и команды** | Только в разрешённых папках. Команды разбираются до запуска; удалённое попадает в корзину; изменения файлов за каждый ход можно отменить. |
| **Расширения** | Навыки (папки с `SKILL.md`) и MCP-коннекторы, у каждого — отобранный каталог. Токены коннекторов хранятся в системном хранилище учётных данных. |
| **Также** | Задачи по расписанию, поиск по прошлым диалогам, десять языков интерфейса. |

## Безопасность

- Пароли, платёжные данные и коды подтверждения никогда не читаются и не вводятся.
- Платежи, удаление и изменения безопасности учётной записи всегда требуют подтверждения.
- Без присмотра выполняются только созданные вами задачи по расписанию; за пределами разрешённого они только читают.
- Входы в аккаунты и файлы cookie остаются на вашем компьютере. Ключ модели отправляется только выбранному вами сервису.

## Быстрый старт

Требуется Python 3.10–3.14.

```bash
git clone https://github.com/wangkant/mibo
cd mibo
python -m pip install -e .
mibo
```

При первом запуске нужно выбрать язык, персонажа и указать ключ модели. При запуске из клона данные хранятся в самом клоне (игнорируются git); установленная копия использует `~/mibo`. `mibo --home DIR` задаёт другую папку.

В macOS и Linux устанавливайте командой `python -m pip install -e ".[app]"`. Управление программами и встроенный браузер доступны только в Windows.

## Разработка

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
ruff check . --select F401,F811,F821,F841
```

CI запускает тесты в Linux (Python 3.10–3.14) и Windows и проверяет установку собранного wheel в чистое окружение. Подробнее — в [CONTRIBUTING](../../.github/CONTRIBUTING.md).
