# Mibo

**내 컴퓨터에서 동작하는 개인용 AI 에이전트. 필요한 일을 말하면 웹, 파일, 다른 프로그램을 넘나들며 끝까지 처리합니다.**

Mibo는 사용자의 컴퓨터에서 사용자가 고른 모델 서비스로 실행됩니다. 중간에 클라우드 머신이 없어 로그인 상태와 파일은 사용자의 컴퓨터에 남고, 모델로 보내는 내용은 사용자가 고른 서비스에만 전달됩니다. 맡긴 작업은 끝까지 수행하고 결과를 보고하며, 예약된 시각에 스스로 실행할 수도 있습니다. 결제처럼 손실이 생길 수 있는 작업, 되돌릴 수 없는 작업, 요청하지 않은 작업 전에만 묻고, 인증 코드, 비밀번호, 결제 정보는 언제나 사용자가 직접 입력합니다. 이름과 모습이 있고 사용자를 기억하는 캐릭터이기도 합니다.

## 기능

| 영역 | |
|---|---|
| **대화** | 한 캐릭터가 창에 나타나며, Windows에서는 데스크톱 위의 모습으로도 나타납니다. 기본 캐릭터나 직접 만든 캐릭터를 사용할 수 있습니다. OpenAI 호환 모델 서비스와 컴퓨터에서 실행 중인 Ollama, LM Studio를 지원합니다. 모델 메뉴에 컨텍스트 사용량이 표시되며 '지금 요약'과 '컨텍스트 비우기'를 제공합니다. |
| **기억** | 사용자에 관한 사실과 계획을 날짜와 함께 기록하며, '설정 › 기억'에서 확인하고 수정할 수 있습니다. 신분증 번호, 카드 번호, 비밀번호, 인증 코드는 저장하지 않습니다. 임시 채팅은 기록을 남기지 않습니다. |
| **외출** | 공개 페이지를 로그인하지 않은 방문자로서 둘러보며 robots.txt를 따릅니다. 페이지는 제목과 표를 유지한 채 한 번에 읽습니다. 웹 검색에는 키가 필요하지 않습니다. |
| **내장 브라우저**(Windows) | 링크가 대화 옆에서 열리며 탭, 비공개 탭, 다운로드를 지원합니다. 캐릭터가 페이지를 살펴보고 클릭, 입력, 선택, 드래그, 파일 업로드를 수행합니다. |
| **메시지** | 메시지에 관해 물으면 캐릭터가 로그인해 둔 사이트를 읽고 새 내용을 알려 줍니다. 이 단계는 읽기만 하며, 페이지는 도구가 없는 모델 호출로 전달됩니다. |
| **다른 프로그램**(Windows) | UI Automation으로 다른 프로그램의 창을 읽고 조작합니다. Electron 앱도 지원하며, 사용자가 키보드와 마우스를 사용하지 않을 때만 조작합니다. |
| **파일과 명령** | 사용자 폴더와 다른 드라이브를 미리 허용하지 않고 사용합니다. 비밀번호, 키, 브라우저 프로필, 다른 프로그램의 데이터가 있는 위치는 읽지 않으며, 설정에서 보기만으로 바꾸거나 회수한 폴더는 그대로 유지됩니다. 무언가가 자동으로 시작되는 위치(시작 프로그램, 프로그램이나 Windows 폴더, PATH의 폴더, Git 훅, 셸 시작 파일)의 변경은 매번 묻고, 웹에서 받은 프로그램이나 바로 가기는 실행하지 않습니다. Word, Excel, PowerPoint 문서는 파일로 만들어 줍니다. 명령은 실행 전에 분석되고, 각 턴의 파일 변경은 되돌릴 수 있습니다. Windows에서는 삭제한 파일이 휴지통으로 이동합니다. |
| **스킬과 커넥터** | 스킬(`SKILL.md`가 있는 폴더)과 MCP 서버. 각각 엄선된 마켓을 제공합니다. 메시지를 `/name`(스킬 이름)으로 시작하면 해당 스킬을 바로 사용합니다. |
| **설정** | 캐릭터는 앱의 설정을 알고 있어, 목록을 보여 주고 해당 항목에서 설정을 열고 하나를 바꿀 수 있습니다. 권한을 넓히지 않는 변경은 바로 적용되며 키는 표시되지 않습니다. |
| **예약 작업** | 알림, 작업, 주기적인 조건 확인. 실행 중에는 읽기와 작업을 만들 때 허용한 작업만 수행합니다. 정기적인 전송이나 게시는 지정한 사이트, 대상, 작업 종류와 문구의 범위 안에서만 실행됩니다. |
| **추천** | 공개된 출처에서 한 번에 하나씩 추천하며, 클릭 수가 아니라 머문 시간으로 순위를 정합니다. 각 카드에는 추천 이유가 표시되고, 피드백과 실행 취소를 지원합니다. |
| **언어** | 10개 인터페이스 언어. |

## 설치

[최신 릴리스](https://github.com/wangkant/mibo/releases/latest)에서 내려받으십시오. 설치 파일에 코드 서명이 없으므로 처음 실행하기 전에 시스템이 경고를 표시합니다.

| 시스템 | 파일 | 처음 실행 |
|---|---|---|
| Windows 10 또는 11(x64) | `mibo-0.2.0-setup.exe` | 브라우저가 파일에 대해 경고하면 '유지'를 선택합니다. SmartScreen에 'Windows의 PC 보호'가 표시되면 '추가 정보'를 선택한 다음 '실행'을 선택합니다. 현재 계정에만 설치되며 관리자 권한이 필요하지 않습니다. |
| macOS(Apple 실리콘) | `mibo-0.2.0-macos-arm64.dmg` | 디스크 이미지를 열고 `mibo.app`을 '응용 프로그램' 폴더로 끌어 옵니다. 앱이 공증되지 않았으므로 처음에는 열리지 않습니다. 메시지를 닫은 다음 '시스템 설정 › 개인정보 보호 및 보안'에서 '그래도 열기'를 선택하고 확인합니다. |

새 릴리스도 같은 방법으로 덮어써서 설치합니다. Windows 설치판은 설정 › 정보에서 스스로 업데이트할 수도 있습니다. 새 버전을 내려받아 릴리스의 체크섬과 대조한 뒤 같은 옵션으로 덮어써서 설치하고 다시 엽니다. 제거해도 데이터 폴더는 남습니다.

### 설치 프로그램 없이 사용

| | |
|---|---|
| **Windows 포터블 버전** | `mibo-0.2.0-windows-x64.zip`을 내려받아 원하는 위치에 압축을 풀고 `mibo.exe`를 실행합니다. 이 파일도 코드 서명되어 있지 않습니다. |
| **Scoop**(Windows) | `scoop bucket add mibo https://github.com/wangkant/scoop-mibo`를 실행한 다음 `scoop install mibo`를 실행합니다. |
| **Homebrew**(macOS, Apple 실리콘) | `brew install --cask wangkant/mibo/mibo`를 실행합니다. |
| **Python으로 설치**(3.10–3.14, 모든 시스템) | `pipx install "mibo[app,web]"` 또는 `uv tool install "mibo[app,web]"`를 실행한 다음 `mibo`를 실행합니다. |

### 소스에서 실행(Linux와 개발)

Python 3.10–3.14가 필요합니다.

```bash
git clone https://github.com/wangkant/mibo
cd mibo
python -m pip install -e ".[app,web]"
mibo
```

`app`은 macOS와 Linux에서 창 구성 요소를, `web`은 외출에 쓰는 Playwright를 추가합니다. 개발하려면 `".[dev]"`를 설치하고 `python -m pytest -q`를 실행하십시오. 자세한 내용은 [CONTRIBUTING](../../.github/CONTRIBUTING.md)(영어)을 참고하십시오.

## 처음 시작

1. 언어, 캐릭터, 모델을 고른 다음 관심 있는 주제와 간단한 자기소개를 입력합니다.
2. 모델은 서비스를 고르고 키를 붙여 넣거나, OpenRouter에 로그인해 무료 모델을 쓰거나, 실행 중인 Ollama 또는 LM Studio를 선택합니다.
3. 키는 시스템 자격 증명 저장소(Windows 자격 증명 관리자, macOS 키체인, Linux의 Secret Service)에 보관되며 파일에는 기록되지 않습니다. 자격 증명 저장소가 없는 시스템에서는 현재 계정만 읽을 수 있는 `credentials.json`에 보관되며, '설정 › 이 컴퓨터'에 그 사실이 표시됩니다.

데이터는 폴더 하나에 모아 저장합니다. 설치본은 `~/mibo`, 소스에서 실행하면 클론한 폴더 자체, 또는 `mibo --home DIR`로 지정한 폴더입니다. 설정은 그 폴더의 `settings.json`에 저장됩니다. Mibo는 기본적으로 로그인 시 시작하며, '설정 › 이 컴퓨터'에서 끌 수 있습니다.

## 개인 정보와 안전

| | |
|---|---|
| **모델 서비스** | 메시지, 관련 기억, 답변에 쓰는 페이지와 파일 내용, 검토가 판단하는 작업 단계를 받습니다. 키는 이 서비스로만 전송됩니다. 안내는 서비스를 처음 저장할 때 한 번 표시되고, 서비스를 바꿀 때만 다시 표시됩니다. |
| **웹사이트** | 외출은 로그인하지 않고 공개 페이지를 읽으며, 기본값은 하루 세 번입니다('설정 › 외출'). 답변에 필요한 페이지도 읽습니다. 로그인 정보는 내장 브라우저에만 남고 그 안에서만 사용됩니다. |
| **기타 서비스** | 답변에 검색이 필요할 때의 검색어, 하루 최대 한 번 GitHub로 보내는 버전 번호, 마켓을 열 때의 목록 조회, MCP 서버 도구에 전달하는 내용. |
| **항상 확인** | 비용이 드는 단계는 어떤 모드에서든 매번 단독으로 확인합니다. 결제나 지출, 되돌릴 수 없는 삭제, 계정 자체, 접근 권한이나 개인 정보 넘기기, 구속력 있는 제출, 실행 취소로 되돌릴 수 없는 이 컴퓨터의 변경이 해당합니다. 이전의 동의나 예약 작업은 여기에 적용되지 않습니다. 휴지통으로 가는 삭제는 확인하지 않습니다. 이런 단계는 카드로 확인하며, 카드의 버튼에는 실행할 작업이 적혀 있습니다. 채팅 입력란에 사용자가 직접 입력한 메시지나 그 카드의 버튼을 누르는 것만 동의로 봅니다. |
| **읽어 들인 내용** | 도구가 웹이나 이 컴퓨터에서 읽어 들인 내용은 자료일 뿐 지시가 아닙니다. 읽은 뒤 지정하지 않은 곳으로 보내는 일은 확인하고, 그 내용을 그대로 옮긴 명령도 확인합니다. 내려받은 프로그램은 실행하지 않습니다. |
| **하지 않는 일** | 비밀번호, 인증 코드, 결제 정보를 대신 입력하는 일(항상 사용자가 직접 입력합니다). 관리자 권한으로 실행하는 일. 모델 키, 앱 설정, 내장 브라우저 프로필을 읽는 일(어떤 도구도 열 수 없습니다). |
| **명령** | Windows에서는 모든 명령이 Windows 자체가 적용하는 제한 아래에서도 실행됩니다. 관리자 권한이 없고, 앱 자체의 파일에 접근할 수 없으며, 속한 프로세스 그룹을 벗어날 수 없고, 클립보드를 쓸 수 없습니다. 읽기만 한다고 판정된 명령은 어떤 파일이나 설정도 변경할 수 없습니다. 브라우저 프로필, 비밀번호 관리자, 지갑, 채팅 앱의 데이터는 모든 명령에 닫혀 있고, SSH와 클라우드 키는 네트워크를 사용한다고 판정된 명령에만 열리며, 어떤 명령도 시작 프로그램 폴더, 셸 프로필, Run 키에 쓸 수 없습니다. 직접 여는 프로그램에는 영향이 없고, 제거하면 모든 권한이 원래대로 돌아갑니다. 관리자 승인을 받는 선택 설정은 네트워크를 사용하지 않는 명령의 연결을 막고 어떤 명령도 예약된 작업을 만들지 못하게 합니다. 그 밖의 파일은 실행 전 분석과 사용자의 동의로 관리합니다. |
| **무인 실행** | 외출과 사용자가 만든 예약 작업뿐입니다. |

모든 전송 대상과 데이터별 보관 위치는 [SECURITY](../../.github/SECURITY.md)(영어)에 정리되어 있습니다.
