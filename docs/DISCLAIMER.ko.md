# 면책 조항

[English](DISCLAIMER.md) · [简体中文](DISCLAIMER.zh-CN.md) · [繁體中文](DISCLAIMER.zh-TW.md) · [日本語](DISCLAIMER.ja.md) · **한국어** · [Español](DISCLAIMER.es.md) · [Français](DISCLAIMER.fr.md) · [Deutsch](DISCLAIMER.de.md) · [Português (Brasil)](DISCLAIMER.pt-BR.md) · [Русский](DISCLAIMER.ru.md)

Mibo는 사용자의 컴퓨터에서 실행되는 소프트웨어입니다. 이 문서는 법률 자문이 아닙니다.

| | |
|---|---|
| **모델 서비스** | 모델 서비스는 사용자가 선택하고 API 키도 사용자가 제공합니다. 메시지, Mibo가 기억하는 사용자 관련 정보, 답변을 위해 읽은 내용은 해당 서비스로 전송되며, 그 서비스의 약관과 데이터 정책이 적용됩니다. |
| **대신 수행하는 작업** | Mibo는 사용자의 승인을 받거나 사용자가 설정에서 정한 범위 안에서 웹사이트, 다른 프로그램, 파일에서 작업합니다. 해당 사이트와 프로그램의 약관이 적용되며, 계정과 그 계정으로 수행되는 작업에 대한 책임은 사용자에게 있습니다. |
| **스킬과 MCP 서버** | 제3자가 작성하고 관리하는 코드로, 각자의 라이선스와 약관이 적용됩니다. 설치 여부는 사용자가 결정합니다. |
| **추천** | 추천 항목은 공개된 출처에서 가져옵니다. Mibo는 그 내용을 검증하거나 보증하지 않으며, 권리는 각 권리자에게 있습니다. |
| **라이선스** | [Apache License 2.0](../LICENSE). 제3자 코드는 각자의 라이선스를 따릅니다([NOTICE](../NOTICE)). 캐릭터 일러스트는 CC BY-NC-SA 4.0입니다([자세히](../mibo/static/characters/LICENSE.md)). |
| **보증 없음** | Mibo는 "있는 그대로" 제공되며 어떠한 보증도 하지 않습니다. 저작자는 이 소프트웨어의 사용으로 발생하는 어떠한 청구, 손해, 손실에 대해서도 책임지지 않습니다. |
